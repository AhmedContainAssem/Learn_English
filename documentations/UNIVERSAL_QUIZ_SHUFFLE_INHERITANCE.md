# Universal Quiz Scoring, Shuffling & Grade Calculation Inheritance Architecture

## 1. Overview
In accordance with pedagogical standards and user requirements, all quizzes across the Learn English platform (including Grade 4, Prep 2, Prep 3, Secondary grades, and all lessons generated from the Admin Studio) automatically inherit:
1. **Dynamic Point Calculations & Score Tracking** (total score, current score, correct/wrong tallies, percentage calculations).
2. **Pedagogical Evaluation Badges** (Honor Roll, Very Good, Good Effort, Needs Practice).
3. **Randomized Question & Option Shuffling** (Fisher-Yates algorithm).
4. **Interactive Audio Pronunciation and Sound Effects** (correct/wrong audio feedbacks, celebratory animations).

## 2. Zero-Config Inheritance Architecture
No manual scoring formulas or JavaScript logic ever need to be written inside individual HTML files. Everything is managed by `/Learn_English/assets/js/quiz-engine.js` and bootstrapped via `/Learn_English/assets/js/main.js`:

1. **Automatic Lifecycle Execution**:
   - `QuizEngine.prototype.loadQuestions(data)` initializes score to `0`, computes total possible points dynamically (`totalPossibleScore`), sets total count (`#total-q`), and applies question shuffling.
   - `QuizEngine.prototype.handleAnswer(option, button, question)` increments the score by 10 points (or custom `question.points`), updates `#score` with live values, plays audio sound effects, disables choices to prevent double-scoring, and displays instant feedback.
   - `QuizEngine.prototype.showResults()` computes final percentage `Math.round((score / totalScore) * 100)`, determines the appropriate pedagogical trophy and grade badge, reports correct answers ratio (`correctCount / total`), and renders the restart button.
   - `QuizEngine.prototype.restartQuiz()` resets scores and reshuffles the questions on demand.

2. **Complete Inheritance for Future Pages**:
   - Any new HTML page only needs standard placeholder IDs (`#current-q`, `#total-q`, `#score`, `#question`, `#options`, `#feedback`, `#next-btn`) and the standard script references:
     ```html
     <script src="../../assets/js/audio.js"></script>
     <script src="../../assets/js/quiz-engine.js"></script>
     <script src="../../assets/js/main.js"></script>
     ```
   - All pages generated by the Admin Studio (`admin/js/generators.js`) automatically include these markup structures and script links. Teachers never write any manual scoring code.

3. **Admin Studio 100% Interactive Parity (WYSIWYG Guarantee)**:
   - The live simulator in `admin/js/preview.js` uses identical scoring rules, option locking, audio feedbacks, and live score updating.
   - When reaching the end of the quiz in the Interactive Preview, the teacher sees the exact same celebratory evaluation screen (Grade Badges, Score Percentage, Correct/Total Ratio, and `🔄 إعادة الاختبار (أسئلة عشوائية)`).
   - What the teacher sees in the Interactive Preview is 100% identical to the final exported HTML page.
