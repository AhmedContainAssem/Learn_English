# سجل التحديثات والتغييرات (Changelog)

جميع التغييرات الموثقة للمشروع مع توضيح الأسباب والتحسينات المنجزة:

## الإصدار v2.5 - مستودع الحالة الذكي (Command Store)، محرك الاستيراد الضخم، والمدقق البيداغوجي

### 🗃️ مستودع الحالة وسجل التراجع الذكي (`StudioStore & Command History`):
- **إضافة موديول `admin/js/store.js`**: تطبيق نمط **Command / Snapshot Pattern** لإدارة سجل التعديلات مع مكدس تراجع (History Stack) ومكدس إعادة (Redo Stack).
- **اختصارات لوحة المفاتيح الاحترافية**: دعم كامل لـ `Ctrl + Z` (Undo) و `Ctrl + Y` أو `Ctrl + Shift + Z` (Redo) مع حماية حقول الإدخال النصية النشطة.
- **أزرار تحكم مرئية وشارة عدد العمليات**: عداد لحظي يوضح عدد العمليات القابلة للتراجع مع إشعارات منبثقة تفاعلية توضح نوع الخطوة المتراجع عنها.

### ⚡ محرك الاستيراد السريع للبيانات الضخمة (`Smart Bulk Ingestion Engine`):
- **إضافة موديول `admin/js/bulk-importer.js`**: معالجة جداول البيانات المنسوخة مباشرة من Word أو Excel أو Google Sheets أو ملفات CSV/TSV.
- **التعرف التلقائي الذكي على الأعمدة**: استخراج وفصل الأفعال (Base, Past, P.P, Meaning)، أو التعريفات والمتلازمات، أو المرادفات والمضادات، أو البوادئ، أو بطاقات المحادثة، أو أسئلة الكويز (السؤال، الخيارات، الإجابة الصحيحة، التلميح).
- **معاينة جدولية حية قبل الاعتماد**: عرض أول 15 صفاً مع خياري الإضافة (Append) أو الاستبدال الشامل (Replace) مع حفظ تلقائي في سجل التراجع `StudioStore`.

### 🩺 المدقق البيداغوجي وفاحص سلامة الروابط (`Pedagogical & Link Quality Linter`):
- **إضافة موديول `admin/js/linter.js`**: فحص وتحليل لحظي لجودة المحتوى التعليمي وسلامة بنية الروابط النسبية.
- **مؤشر صحة الدرس اللحظي (Content Quality Score 0-100%)**: تقييم مستمر يصنف المحتوى (ممتاز 🏆، جيد مع ملاحظات ⚠️، بحاجة لمراجعة ❌).
- **معالجة التوازن التربوي**: التحقق من وجود إجابة صحيحة واحدة لكل سؤال، توازن عدد الخيارات المشتتة (Distractors)، وجود شروحات تعزيزية، اكتمال تصريفات الأفعال ومعانيها.
- **زر التصحيح التلقائي الذكي (1-Click Smart Auto-Fix)**: إصلاح الملاحظات وتعبئة التلميحات الافتراضية وضبط وسوم الحالات بضغطة زر واحدة.

## الإصدار v2.0 - مستكشف شجرة المناهج، محاكي الأجهزة المتجاوب، وعقد البيانات فائق الدقة

### 🌳 مستكشف شجرة المناهج والملفات التفاعلي (Visual Curriculum & File Tree Explorer):
- **إضافة موديول `admin/js/tree-explorer.js`**: مستكشف مرئي هرمي متكامل لجميع المناهج والمراحل (`Prep_3`, `Prep_2`, `Prep_1`, `Sec_1`, `Sec_2`, `Sec_3`, `Grade_4`, `Grade_5`, `Grade_6`, `Course`) والوحدات والدروس.
- **إجراءات مباشرة بضغطة زر واحدة**: فتح أي ملف للتعديل الفوري في الاستوديو، أو إضافة وحدة جديدة للمرحلة، أو إنشاء درس فوري داخل أي وحدة بالمسارات الصحيحة تلقائياً.
- **بحث وتصفية ذكية (Live Search)**: إمكانية البحث الفوري في جميع أسماء المناهج والمراحل والوحدات والدروس.
- **ملف شجرة المناهج المركزي (`curriculum-manifest.json`)**: توثيق وهيكلة كامل خريطة المنصة في ملف موحد لتسهيل التوسع المستقبلي.

### 📱 محاكي الأجهزة المتجاوب (Device Viewport Switcher):
- **التبديل الفوري بين أنماط العرض**:
  - 🖥️ **شاشة حاسوب كاملة (100% Fluid Desktop)**.
  - 💻 **شاشة جهاز لوحي (Tablet 768px × 1024px)** مع إطار وحواف مخصصة.
  - 📱 **شاشة هاتف محمول (Mobile 375px × 667px)** مع إطار هاتف واقعي.
- **معاينة حية ومطابقة تامة**: مشاهدة تجربة الطالب على مختلف الأجهزة بدقة قبل النشر.

### 💎 عقد البيانات فائق الدقة (Lossless Roundtrip Data Contract Payload):
- **تضمين عقد البيانات التلقائي**: تضمين وسيلة تخزين مهيكلة `<script id="studio-payload" type="application/json">` داخل كل ملف HTML يولده الاستوديو.
- **استيراد فوري بدون أي فقد للبيانات (100% Lossless Roundtrip)**: استعادة كافة البطاقات والخيارات والحقول بدقة تامة وبأقل استهلاك للموارد.

## الإصدار السابق - نظام الفهارس الثنائي واستيراد وتعديل الملفات والمراحل المخصصة

### 📑 نظام الفهارس الثنائي (Dual-Index System):
- **فهرس المرحلة الدراسية (Stage Index / Main Grade Hub)**: إنشاء وتخصيص صفحات فهارس المراحل (`Learn_English/{Stage}/index.html`) مع ربط سلس بالوحدات والكورسات.
- **فهرس الوحدة الفرعية (Unit Index / Subfolder Hub)**: إنشاء وتخصيص صفحات فهارس الوحدات (`Learn_English/{Stage}/{Unit}/index.html`) مع توجيه دقيق للدروس والكويزات.
- **مساعد الروابط الذكي (Smart Link Assistant)**: دعم توجيه البطاقات لأي ملف درس بنفس المجلد، أو مجلد فرعي `unit-X`، أو مرحلة أخرى، أو رابط مخصص مع شرح مسار الرابط للناشر.
- **تبديل حالة الإتاحة بضغطة زر واحدة (1-Click Status Toggle)**: إمكانية قفل أو فتح أي بطاقة أو درس (متاح 🟢 / قريباً 🔒) وتحديث وسم الحالة فوراً.

### 📥 محرك استيراد وتحليل وتعديل الملفات القائمة (Universal HTML Importer):
- **إضافة موديول `admin/js/importer.js`**: قراءة وتحليل أي صفحة HTML موجودة في المنصة سواء كانت درساً تفاعلياً، بطاقات، كويز، أو فهرساً عبر `DOMParser` أو عبر حمولة JSON المضمنة.
- **تكامل السحب المباشر من GitHub API أو النماذج أو اللصق اليدوي**: تمكين المعلم من سحب أي ملف من المستودع مباشرة وتعديله وإعادة نشره لنفس المسار دون أي فقدان للبيانات.

### 🏫 منظومة إدارة المراحل والأقسام المخصصة (Custom Educational Stages Manager):
- **إدارة المراحل المخصصة (Stages Manager Modal)**: إمكانية إضافة أي مرحلة دراسية، صف دراسي، أو كورس جديد بالاسم والمجلد والأيقونة والتصنيف وحفظها محلياً.
- **تأسيس الفهرس التلقائي للمرحلة (1-Click Stage Index Scaffolding)**: توليد هيكل فهرس المرحلة المخصصة وتجهيزه للنشر فوراً.

### 🏛️ توحيد وراثة التصميم والمنطق المشترك (CSS & JS Inheritance - DRY):
- **إعادة هيكلة `admin.css`**: إزالة الكلاسات المكررة والاعتماد المباشر على وراثة المتغيرات والبطاقات والأزرار والخطوط والتبويبات من `assets/css/style.css`.
- **توحيد دوال الصوت والحركة**: استدعاء دوال `speakText()` و `flipCard()` و `playSound()` المركزية في جميع أرجاء استوديو المعلم والمحاكي والصفحات المولدة دون تكرار أي سطر برمجي.
- **تكامل محرك الاختبارات المركزي**: ربط الصفحات المولدة بمحرك الاختبارات الموحد `assets/js/quiz-engine.js`.

### 🔒 أمان رمز المرور الخالي من التسريبات (Zero-Leak Security):
- **حذف الرمز الافتراضي المكشوف**: إزالة أي رموز أو كلمات مرور ثابتة مثل ("2025") من الشيفرة البرمجية والواجهة نهائياً.
- **مسار التهيئة الأولية للمرة الأولى (First-Time Setup Flow)**: إتاحة تعيين رمز مرور المعلم السري لأول مرة بشكل آمن وتأكيده وحفظه محلياً في متصفح المعلم فقط (`localStorage`).
- **شاشة تحقق وتغيير سرية**: واجهة قفل سلسة لا تقدم أي تلميحات، مع إمكانية تحديث الرمز في أي وقت بعد التحقق من الرمز السابق.

### 🎴 محرك بطاقات التقليب التفاعلية (3D Flashcards Engine):
- **تأثير التقليب ثلاثي الأبعاد (3D Perspective Flip)**: بناء نظام تقليب فيزيائي سلس للبطاقات في كل من المحاكي المباشر والصفحات المولدة مع تأثيرات بصرية وانعكاس الوجهين الأمامي والخلفي.
- **أزرار النطق الصوتي الفوري**: إمكانية الاستماع لنطق الكلمات والمصطلحات الإنجليزية مباشرة من واجهة البطاقة وداخل محرر البيانات.
- **دعم كافة الهياكل المنهجية**: توحيد فئات CSS للبطاقات عبر كافة دروس الموقع (`.flashcards-grid`, `.flashcard`, `.card-face`, `.card-front`, `.card-back`).

### 🧹 الهندسة البرمجية وتفكيك الملفات الضخمة (Modular Refactoring):
- تفكيك ملف `admin/index.html` الأحادي الضخم إلى هيكلية معيارية نظيفة:
  - `admin/css/admin.css`
  - `admin/js/state.js`
  - `admin/js/editor-ui.js`
  - `admin/js/preview.js`
  - `admin/js/generators.js`
  - `admin/js/github.js`
- الالتزام بمبدأ فصل المسؤوليات (Separation of Concerns) وسهولة التوسع والصيانة.
