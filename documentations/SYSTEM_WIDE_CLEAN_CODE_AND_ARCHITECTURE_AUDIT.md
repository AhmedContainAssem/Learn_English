## 1. مبادئ المعمارية المطبقة (Architectural Principles Audit)

### أ. معمارية الـ Jamstack (Static & Client-First)
- **الاستقلالية التامة**: المنصة تعمل بنسبة 100% كملفات ثابتة (HTML5 / Modern CSS / Vanilla JS).
- **صفر تبعيات خلفية (Zero Backend Dependencies)**: لا تتطلب خوادم Node.js أو قواعد بيانات لتشغيل المحتوى التعليمي.
- **تخزين محلي آمن**: حفظ الإعدادات، المسودات، ورموز المرور يتم عبر `localStorage` في متصفح المعلم، مع آليات التشفير والـ In-Page Modals.
- **نشر مباشر بدون وسيط**: النشر إلى مستودع GitHub يتم مباشرة من المتصفح عبر GitHub REST API v3 مع دعم التنزيل الفوري كـ Fallback.

### ب. فصل الاهتمامات (Separation of Concerns - SoC)
- **بيئة الطالب (Student Environment)**:
  - تعتمد كلياً على حزمة `assets/css/style.css` و `assets/js/`.
  - معزولة تماماً وخالية من أي كود إداري أو أزرار تحكم خاصة بالمعلم.
- **بيئة المعلم والاستوديو (Admin Studio)**:
  - معزولة في مجلد `admin/` مع كود CSS مستقل (`admin/css/admin.css`) ووحدات JS متخصصة (`admin/js/`).
  - ترث المتغيرات والتصميم العام من المنظومة المركزية دون تكرار.

### ج. مبدأ عدم التكرار والوراثة (DRY & CSS/JS Inheritance)
- **شجرة الـ Design Tokens**:
  - تم توحيد كافة الألوان والظلال والمسافات في `variables.css`.
  - يتم استيرادها مركزياً عبر `style.css` لترثها جميع الصفحات وقوالب الدروس ولوحة الإدارة.
- **محركات التشغيل الموحدة (Engines)**:
  - محرك الصوتيات (`audio.js`): استدعاء صوتي موحد عبر SpeechSynthesis API.
  - محرك الاختبارات (`quiz-engine.js`): خوارزمية Fisher-Yates العشوائية الموحدة لكافة الاختبارات.
  - محرك التبويبات (`tabs.js`) ومحرك القصص (`story-engine.js`).

### د. الكود النظيف والتخلص من الـ AI Slop (Clean Code)
- **غياب الستايلات المضمنة**:
  - تم تطهير صفحة `admin/index.html` من 237 ستايل مضمن وتحويلها بالكامل إلى فئات معيارية دقيقة.
  - صفحات الطلاب وقوالب المناهج خالية تماماً من التنسيقات المبعثرة.
- **الأمان وتجربة المستخدم**:
  - استبعاد استخدام `window.prompt` و `window.alert` تماماً واستبدالها بنوافذ منبثقة داخلية مخصصة (`custom-modal-overlay`) لضمان التوافق التام مع متصفحات الموبايل والـ Sandboxed Iframes.
