# 🚀 دليل القوالب الجاهزة لمستر أحمد عاصم

هذا المجلد يحتوي على **قوالب جاهزة 100%** لإنشاء أي درس أو حصة جديدة في ثوانٍ معدودة دون الحاجة لإعادة كتابة كود الـ HTML أو الـ CSS أو الـ JS من الصفر!

---

## 📁 محتويات المجلد:

1. **`lesson-quiz-template.html`**  
   👉 **قالب الاختبار التفاعلي السريع (Direct Quiz)**: مخصص للدروس المعتمدة على أسئلة الاختيار من متعدد مع النطق الصوتي الفوري، العداد، واحتساب النقاط.
   
2. **`lesson-tabs-template.html`**  
   👉 **قالب المنهج الدراسي بالتبويبات (Curriculum Tabs)**: يحتوي على تبويبات جاهزة (مفردات بجدول وأزرار نطق + شرح القواعد + كويز تفاعلي).

3. **`course-session-template.html`**  
   👉 **قالب كورسات المحادثة (Flashcards & Dialogue)**: يحتوي على بطاقات الفلاش كارد التفاعلية ثلاثية الأبعاد + المحادثة الصوتية + الواجب والاختبار.

---

## ⚡ كيف تنشئ درساً جديداً في 3 خطوات فقط؟

1. **انسخ ملف القالب** (`lesson-quiz-template.html` أو `lesson-tabs-template.html`) إلى مجلد الوحدة المناسب (مثلاً داخل `Grade_4/unit-1/` أو `Prep_3/unit-2/`).
2. **أعد تسمية الملف** لاسم الدرس (مثلاً `lesson-2.html` أو `session-3.html`).
3. **افتح الملف وعدل فقط الأماكن المحددة بعلامة `✏️`**:
   - اسم الدرس ووصفه
   - قائمة الأسئلة والخيارات داخل `window.lessonData`
4. **احفظ الملف وافتحه في المتصفح**.. مبروك! الدرس يعمل بكامل مؤثراته الصوتية والبصرية ومحرك الاختبارات تلقائياً.

---

> 💡 **أو استخدم لوحة التحكم المرئية السريعة**: يمكنك أيضاً فتح صفحة الأدمن (`admin/index.html`) وتصميم الدرس وكتابة أسئلته وتنزيل ملف HTML جاهز بضغطة زر واحدة!
